# 🚀 数学星球 Math Planet（Grade 6 亲子互动版）

面向 IB 国际学校 6 年级学生的英中双语互动数学练习 H5 应用，完整覆盖六年级课程概要全部单元，由易到难（热身 → 挑战 → 高手），以星星激励、徽章成就、错题重练、奖励兑换等方式帮助孩子建立数学兴趣。

> 单文件应用：整个程序就是一个 `index.html`，无需安装、无需联网即可运行。

---

## 📚 覆盖单元（Term 1–3 完整课程概要）

| Term | 单元 | 图标 | 知识点（热身 → 高手） |
|---|---|---|---|
| Term 1 | 因数与倍数 | 🔢 | 因数/倍数/质数 → HCF、LCM → 分组问题、公车班次 |
| Term 1 | 正负数 | 🌡️ | 数轴加减、零下温度 → 负数运算、温差 → 多步运算、潜水艇 |
| Term 1 | 代数表达式 | 📐 | 表达式含义、代入 → 文字翻译成代数式、化简 → 周长代数式、n² |
| Term 2 | 小数与分数 | 🍕 | 互转、比较 → 加减、通分 → 求部分量、购物找零 |
| Term 2 | 统计 | 📊 | 平均数、读条形图 → 中位数、众数 → 图表分析、总和反推 |
| Term 3 | 角与多边形 | 🔺 | 角的分类、内角和 → 求未知角、多边形内角和 → 反求边数、钟面夹角 |
| Term 3 | 比 | ⚖️ | 比的意义、化简 → 按比分配、比例尺 → 综合应用 |

每单元 3 关 × 4 题，共 **84 道内置双语题** + 家长可无限自定义。全部严格限定在六年级范围内，不超纲。

## ☁️ 云端同步（家长手机 ↔ 孩子手机）

应用自带一个**轻量自托管同步服务器**（`sync-server.js`，纯 Node、零依赖），两台设备设置相同服务器地址、加入同一房间码后，进度自动双向同步（孩子答题，家长手机实时看到星星/关卡/错题变化）。

### 第一步：部署同步服务器（任选其一，约 5 分钟）

1. **Render（免费，推荐）**
   - 注册 https://render.com → New → Web Service
   - 连接本仓库（或上传 `sync-server.js` 到任意 GitHub 仓库）
   - Build Command 留空，Start Command 填：`node sync-server.js`
   - 部署完成后会得到 `https://你的服务名.onrender.com`
2. **家里电脑 / 任何有 Node 的机器**
   ```bash
   node sync-server.js        # 默认端口 8787，数据存 ./data/
   PORT=8080 node sync-server.js
   ```
   局域网内手机访问时填 `http://电脑IP:8787`；跨网络需内网穿透或公网服务器。
3. **Railway / Fly.io / VPS** 同理，启动命令都是 `node sync-server.js`。

### 第二步：两台设备配置

1. 家长手机打开 App → 家长模式（密码 2468）→ 设置 → 云端同步
2. 填入服务器地址（如 `https://xxx.onrender.com`）→ 保存
3. 点 **"开启云端同步"** → 得到一个同步码（如 `mpabc123xyz`）
4. 孩子手机：同样填服务器地址 → 粘贴同步码 → **"加入同步"**

之后两台设备约每 6 秒自动同步一次；答完一题也会立刻推送。不想用云同步时，用"数据 → 进度码"手动同步即可。

> ⚠️ 说明：2024 年起 kvdb/jsonblob 等免费公共 JSON 存储均要求注册或付费，因此同步采用"自托管服务器"方案——数据完全由家庭自己掌控，不经过任何第三方。

## 🚀 快速使用

### 方式一：本机直接打开（最省事）
用浏览器（手机 Chrome/Safari 均可）直接打开 `index.html` 即可玩。进度保存在浏览器里。

### 方式二：部署成链接，微信分享（推荐）
1. 把本项目推到 GitHub 仓库（默认已配置 GitHub Pages）
2. 仓库 Settings → Pages → Source 选 `main` 分支 / (root)
3. 得到链接 `https://<你的用户名>.github.io/<仓库名>/`
4. 把链接粘贴到微信聊天发送，孩子点开即玩

> 💡 微信打开链接后，点击右上角"···"还可以"发送给朋友"，方便转发到家庭群。
> ⚠️ 不同手机上进度默认分开保存；需要互通就用上面的"云端同步"。

## 👨‍👩‍👧 亲子互动玩法建议

1. **同屏陪学**：孩子答题，家长在旁引导；卡住时点"💡 小提示"，再不行点"📖 讲解"。
2. **读题模式**：不熟悉英文的孩子点"🔊 读题"听题目。
3. **奖励约定**：家长模式 → 奖励里设置孩子心动的奖励（如看动画片、买书），约定"攒 30 星兑换"。
4. **错题复盘**：每周和孩子一起打开"错题本"重练，做对 5 道解锁"错题征服者"徽章。
5. **自定义出题**：家长模式 → 出题，紧跟学校进度补充课本题目。
6. **云端陪伴**：孩子用平板答题，家长手机开着"数据"页，随时看到进度和打卡情况。

## 🛠️ 技术说明

- 纯前端单文件：HTML + CSS + Vanilla JS，无任何外部依赖；同步服务器为纯 Node 零依赖
- 数据保存在 `localStorage`（键 `mathPlanet_v1`）；同步数据保存在服务器 `./data/`
- 兼容微信内置浏览器、手机 Chrome/Safari、桌面浏览器
- 语音朗读使用 Web Speech API，不支持时自动降级
